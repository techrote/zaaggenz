# Worked creative and research workflows

These are target end-to-end workflows used to keep individual issues integrated. Exact UI labels may evolve; the state ownership and evidence requirements should not.

## 1. From protected source to melodic zaag phrase

1. Open a recovered `locked_bloom`-compatible project and confirm the frozen identity render.
2. Choose a `TuningSpec` / keyboard mapping; audition notes without changing BPM or source tail semantics.
3. Place notes/rests/roll gestures on the timeline using source-preserving mode.
4. Add a simple sonority progression while keeping SUB or low BODY fixed if desired.
5. Add a fourth-bar variation window, render 4/16 bars, compare against the source slot and save the immutable recipe.

Evidence: source-identity check, tuning targets, timeline save/reopen, full SYNTHLINE stem, named render hashes.

## 2. Spectral Auto-Tune / Chordness exploration

1. Select a source/interval and run the shared multiresolution/component analysis.
2. Inspect confidence, transient/remainder material and target-comb geometry.
3. Audition retune-only and reweight-only at low amount before hybrid processing.
4. Compare pre-shaper vs post-shaper placement under matched output policy.
5. Keep root/low anchor fixed, move upper groups through a progression, then save a new source-family candidate instead of overwriting the protected preset.

Evidence: identity bypass, requested/source/realised component plots, component movement bounds, level-matched A/B, method/version metadata.

## 3. Timbre-derived tuning without “automatic truth”

1. Analyse a stable timbre window and compute a versioned dissonance curve.
2. Display local minima as **candidate intervals** with sensitivity to partial subset/window/level.
3. Choose or reject candidates manually; configure home root, drift limits and voice-leading.
4. Render an adaptive-tuning phrase plus the fixed-tuning control.
5. Judge compatibility/source identity separately from personal preference.

Evidence: dissonance-method version, minima/sensitivity, bounded-drift trace, matched listening recipe.

## 4. Phrase variation and linked fake-out

1. Author `establish → repeat → reinforce → vary/tease → return` roles.
2. Choose one slower metrical level to remain stable and one faster layer to vary.
3. Design a fake-out where the expected impact is replaced by a sparse/upper event that gradually acquires the expected destination identity.
4. Generate controlled no-violation/recovery-only/violation-only/linked variants without changing the final landing.
5. Use the ordinary musical version freely; freeze matched variants only if running the research protocol.

Evidence: role plan, clock/phase trace, gesture trajectories, event inventory, return-time equality where required.

## 5. Text or vocal gesture to editable arrangement

1. Write a mnemonic sequence such as `bu budu budubu ...` using the user's own dictionary, or explicitly record/import a short vocal imitation.
2. Extract/author onset, accent, duration, pitch tendency and brightness/opening contour with confidence.
3. Inspect/correct the structured gesture before applying it.
4. Map it to notes/rolls and timbral automation while preserving the selected source topology.
5. Save the structured gesture so the raw vocal sample is not required for future rendering if the user chooses to discard it.

Evidence: timing/contour confidence, manual corrections, compiled `GestureSpec`, no hidden dependence on external services.

## 6. Controlled listening study

1. Start from accepted creative recipes—not mutable UI screenshots.
2. Materialise exact stimulus WAVs; record hashes, excerpt boundaries, level matching and peak diagnostics.
3. Freeze `TrialSpec`/analysis in ZG-040 tooling before confirmatory collection.
4. Present counterbalanced trials with task-specific endpoints; record replay/missing/effort data separately.
5. Analyse the predefined contrasts, then clearly separate exploratory follow-ups.
6. Feed results back into preset/documentation decisions only through explicit review; a null result leaves the creative feature available if it is otherwise useful.

Evidence: frozen manifest, stimulus identities, deviation log, effect estimates/uncertainty and reproducible report.
